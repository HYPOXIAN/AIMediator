A review of every file in the workspace, after the reorganization was complete,
to find and remove dead files: stale reports, unused JSON and stale test or
run output.

## Method

- Tracked files (194): for each file outside `src/aimediator/*.py` and
  `tests/`, count the other tracked files that name it; for each package
  module, count its importers; for each `reports/` directory, check its
  manifest and the documents that cite it.
- Ignored files: compare each file in `data/raw/` and `data/processed/` with
  its dataset `manifest.json`; inspect `runs/`, `dist/` and caches.
- `python3 scripts/maintenance/check_rules.py` before and after.

## Findings

- **Tracked tree: no dead files.** Every report directory is cited by a
  document and has a manifest (P2). Every configuration file is used by a
  script or named by a dataset manifest. Every package module has an importer.
  The `.zh` prompts are loaded by language suffix. The remaining experiment
  scripts take their run as an argument and are not one-off scripts; they
  were classified in the reorganization (change record, P3-D02).
- **Raw data: none removed.** Every file in `data/raw/` (including
  `checkpoint.json`, `request-log.json` and the `api-*` files) is listed in
  its dataset manifest, and `data/raw/` is read-only (P1).
- **Stale run output: `runs/`** held only the working output of the finished
  reorganization: rule-check snapshots `reorg-p1` to `reorg-p5`, migration
  drafts `reorg-p2` to `reorg-p4` and the batch 2 archive verification logs
  (`reorg-p2-archive-log/`, 18 JSON files). The change record
  [20261103-reorganization.md](20261103-reorganization.md) names these
  files as saved, ignored output.
- **Caches:** `__pycache__/` in `scripts/`, its three subdirectories,
  `src/aimediator/` and `tests/` (about 1.4 MiB).
